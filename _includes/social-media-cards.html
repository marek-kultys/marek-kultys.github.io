{%- comment -%} page_title and page_description are computed in _layouts/main.html, so the card and the browser tab can never disagree. og:url was site.data.mk.url on every page, i.e. every shared link previewed as the homepage. It is now the page's own address. og:image uses the post's own image where it has one. `default` is load-bearing: one post carries an empty `image:` key, and Liquid treats an empty string as TRUTHY, so an `if page.image` test would emit the site URL with nothing after it. `default` catches nil and empty alike. (Liquid tags are NOT inert inside an HTML comment, which is why that test is spelled out in prose here rather than written as a tag.) A relative og:image is invalid — scrapers do not resolve it against the page — so the host is prepended here. A second, relative og:image tag used to sit below this block and has been removed; two og:image tags let a scraper pick the wrong one. {%- endcomment -%}
